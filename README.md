STAT-API provides a comprehensive sports data API delivering play-by-play data for major leagues (NFL, NBA, MLB, NHL, PGA Tour) and daily fantasy contest results from DraftKings and FanDuel, with tiered pricing starting at $49 per month and a free preview of sample data. The service offers real-time updates, historical archives, and extensive data dictionaries, supporting developers with SDKs, GraphQL, and detailed documentation.

**Areas:** Sports · Data · API · DFS · Fantasy

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for stat-api-com: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
